## Зачем отслеживаю

Хочу купить автоматическую кофемашину для дома и не переплатить. Цены на кофемашины
в голландских магазинах заметно скачут: акции, распродажи (Black Friday, Sinterklaas,

только то, что реально влияет на решение о покупке.

## Что считается «ценой» (контракт скилла `extract-price`)

Скилл по одному URL возвращает объект:

```json
{ "regular_price": 719.99, "sale_price": 687.92, "has_credit": true }
```

| Поле | Тип | Что это | Если не найдено |
|---|---|---|---|
| `regular_price` | число, EUR | Обычная цена без скидки. Если на странице есть зачеркнутая цена или «Adviesprijs» — это она. Если скидки нет — текущая цена. | `null` (например, товар снят с продажи) |
| `sale_price` | число, EUR | Цена со скидкой, которую сейчас платит **любой** покупатель. | `null`, если скидки нет |
| `has_credit` | `true`/`false` | Для этого товара предлагается рассрочка или кредит: «in termijnen», «gespreid betalen», «in3», «Klarna», «p.m.». | `false` |

Правила:
- Цены — числа в евро с точкой как разделителем копеек (`687.92`), без знака €.
- Цены «для участников программы», «с промокодом», «Tweedekans» (б/у) и цены
  комплектов с аксессуарами **не учитываем**: берем цену самого товара, доступную без логина.
- `has_credit` ставим по признакам **именно этого товара**, а не по общему блоку
  способов оплаты в подвале сайта (там «Klarna»/«termijnen» есть на каждой странице).
- Если товара нет в наличии, но цена показана, берем ее; если цены нет — оба поля `null`.

## Заметки для `extract-price`

- **ep.nl**: надежный источник цены — JSON-LD `"@type":"Product"` → `offers.price`.
  Рекомендованная цена — в `aria-label="Price X, advised price Y"` у основного блока цены
  (на странице есть и цены аксессуаров — их не брать). Рассрочка — `"payInTerms":true`.
- **coolblue.nl**: цена — JSON-LD `offers.price` или `salesPrice.includingVat`;
  зачеркнутая цена — `listPrice` (если `null`, скидки нет). Рассрочка в HTML
  для товара не видна — уточним при сборке скилла.
