# extract-price

Базовый кирпичик трекера цен: **один URL на входе → один объект цены на выходе.**
Ниша и правила определения цены описаны в `NICHE.md` в корне репозитория.

## Контракт

**Вход:** один URL страницы товара (`https://…`). Без логина, без корзины.

**Выход:** ровно один JSON-объект и ничего больше:

```json
{ "regular_price": 719.99, "sale_price": 687.92, "has_credit": true }
```

| Поле | Тип | Значение |
|---|---|---|
| `regular_price` | число (EUR) или `null` | Обычная цена без скидки: зачеркнутая цена / «Adviesprijs», а если скидки нет — текущая цена. `null` — цена не найдена. |
| `sale_price` | число (EUR) или `null` | Цена со скидкой, которую сейчас платит любой покупатель. `null` — скидки нет (или цена не найдена). |
| `has_credit` | `true` / `false` | Для **этого товара** предлагается рассрочка/кредит. `false` — нет или не удалось определить. |

Инварианты (проверяй перед ответом):
- если `sale_price` не `null`, то `sale_price < regular_price`;
- если `regular_price` равно `null`, то и `sale_price` равно `null`;
- числа — с точкой, максимум 2 знака после запятой, без валюты и пробелов (`1299.0`, `687.92`).

## Как выполнять

1. **Запусти помощник** (страницы весят ~1,5 МБ — не читай HTML целиком в контекст):

   ```bash
   python3 .claude/skills/extract-price/extract.py "<URL>"
   ```

   - stdout — готовый объект контракта;
   - stderr — диагностика: откуда взята цена или почему не нашлась;
   - код выхода: `0` — цена найдена, `1` — страница открылась, но цены нет, `2` — страницу не загрузить.

2. **Верни stdout как есть** — один JSON-объект, без пояснений вокруг, если тебя вызвал другой
   скилл (например, `tracker`). Если спрашивает человек — можно добавить одну строку
   комментария под объектом (например, причину `null` из stderr).

3. **Если помощник не справился** (код `1`, а цена на странице явно есть, или магазин новый) —
   извлеки цену вручную по той же логике (ниже), точечно: `curl` + `grep`/`python`,
   а не чтение всей страницы. Если причина в смене верстки — предложи поправить `extract.py`.

## Логика извлечения

**1. Загрузка страницы.** GET по URL с обычным браузерным `User-Agent` и
`Accept-Language: nl-NL`. Ответ 403/таймаут → страница недоступна → объект с `null`.

**2. Текущая цена** (по приоритету):
1. JSON-LD `<script type="application/ld+json">` → объект `"@type": "Product"` → `offers.price`
   (или `offers.lowPrice`). Самый надежный источник: его магазины отдают для поисковиков.
2. Microdata `itemprop="price"` или OpenGraph `product:price:amount`.

**3. Обычная (зачеркнутая) цена и рассрочка — по магазину:**

| Магазин | Обычная цена | Рассрочка |
|---|---|---|
| ep.nl | `aria-label="Price X, advised price Y"` у блока цены, где `X` = текущая цена → `Y`; плюс `originalPrice` в данных товара. Берем наибольшую. | `"payInTerms":true` в блоке данных именно этого товара |
| coolblue.nl | `"listPrice":{"includingVat":Y}` рядом с `"salesPrice":{"includingVat":X}`, где `X` = текущая цена. `listPrice: null` → скидки нет. | В HTML для товара не видна (подгружается скриптом) → `false` |
| другие | только текущая цена | `false` |

Цены аксессуаров, комплектов, «Tweedekans» (б/у) и цены «по промокоду» — игнорируем:
сопоставляем все найденные значения с текущей ценой товара из JSON-LD.

**4. Нормализация чисел:** убрать валюту, пробелы и неразрывные пробелы;
`1.299,00` → `1299.0`, `687,92` → `687.92`, `1,299.00` → `1299.0`. Ноль и отрицательные — не цена.

**5. Сборка ответа:**
- `regular_price` = максимум из (текущая цена, найденные обычные цены);
- `sale_price` = текущая цена, если она меньше `regular_price`, иначе `null`;
- цена не найдена → `{ "regular_price": null, "sale_price": null, "has_credit": false }`.

## Примеры

```text
URL:   https://www.ep.nl/product/philips-ep5549-70-1452003
Ответ: {"regular_price": 719.99, "sale_price": 687.92, "has_credit": true}

URL:   https://www.coolblue.nl/product/945962/philips-lattego-5500-ep5547-90.html
Ответ: {"regular_price": 627.0, "sale_price": null, "has_credit": false}
```

## Известные ограничения

- bol.com и mediamarkt.nl отвечают 403 (защита от роботов) — для них всегда `null`.
- Coolblue: `has_credit` всегда `false` — признак рассрочки для товара в HTML отсутствует.
